### 👨‍💻 About Me

Informatics Engineering student at **Universitas Muhammadiyah Malang** with a practical, hands-on engineering mindset. Focused on designing and building end-to-end software solutions—from responsive web platforms and cross-platform mobile apps to microcontroller-based hardware prototypes.

- 🔭 Currently developing **ServiceIn**, a mobile motorcycle workshop booking app with payment gateway integration.
- ⚙️ Experienced in **Laravel, React, React Native (Expo)**, and **ESP32** hardware prototyping.
- 🎯 Approaching software architecture and debugging systematically through empirical testing and clean logic.
